# EPSO AD5 2026 Competition Simulator (IRT Edition)

> **Note:** This project is **100% vibe-coded** — built as a self-contained, single-file interactive psychometric simulator with zero external runtime dependencies.

An interactive, client-side web application for exploring pass rates, score distributions, essay-marking cutoffs, and reserve list probabilities for the **EPSO AD5 2026** generalists competition using **3-Parameter Logistic (3PL) Item Response Theory**, exact **Poisson-Binomial dynamic programming**, bivariate **Gauss-Hermite quadrature**, and **5D correlated Common Random Numbers (CRN) Monte Carlo** simulation.

## Quick Start & GitHub Sharing

Because the entire application lives inside a single self-contained [`index.html`](./index.html) file (HTML + CSS + vanilla JavaScript, system fonts only, zero external CDN or npm runtime dependencies):

1. **Run locally (no build step required):** Clone or download the repository and double-click `index.html` in any modern desktop or mobile browser.
2. **Host on GitHub Pages in 30 seconds:**
   - Fork or push this repository to GitHub.
   - Open **Settings → Pages**.
   - Under **Build and deployment**, set **Source** to **Deploy from a branch**, select your default branch (`main`) and `/ (root)`, and click **Save**.
   - GitHub Pages will serve `index.html` directly as a shareable static link.

## Key Features

- **3PL IRT Psychometric Engine:** Real-time calibration of item discrimination ($a_k$) and mean difficulty ($\bar{b}_k$) from user Mean & SD sliders using 41-node Gauss-Hermite quadrature, heterogeneous item difficulty banks ($\sigma_b$), speededness-adjusted pseudo-guessing floors ($c$), feasibility clamping badges, and marginal reliability ($\alpha$) readouts.
- **Exact Poisson-Binomial Conditional Scoring:** Precomputed on a 101-point $\theta \in [-4.2, +4.2]$ grid via exact dynamic programming.
- **Bidirectional Part 1 Sync:** Dragging any Verbal / Num+Abs Mean or SD slider (or latent correlation $\rho_{VN}^\theta$) updates the Joint Pass Rate slider automatically; dragging the Joint Pass Rate slider solves for an equal shift $\Delta\mu$ across both means via bisection (with graceful bound clamping).
- **Zero-Flicker Correlated Simulation:** 5×5 latent correlation matrix with automatic nearest-PSD projection and Cholesky decomposition, driving 40,000 fixed CRN Part 2 draws plus 3,000 dedicated posterior CRN draws per integer Verbal score (`10–20`).
- **Interactive High-DPI `<canvas>` Charts:**
  - Part 1 Verbal Score Distribution (`0–20`) with dynamic emerald green contender zone ($v^*$ shifting live whenever conditional reserve-list odds exceed baseline passer odds).
  - Part 2 Preliminary (Top `2,235`) vs. Final (Top `1,490`) histogram toggle with live cutoff and Personal Score reference lines.
- **Personal Score Tester & Odds Table:** Click any Verbal row (`13/20`–`20/20`) to load it into the tester, inspect exact margins/ranks, and catch cases where a strong essay is blocked at the Top `2,235` gate.
